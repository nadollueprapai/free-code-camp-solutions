# n-queens-solver
This is a solution for the N Queen puzzle, posed by freeCodeCamp. 

It utilizes backtracking/recursion to solve the classic algorithmic puzzle:
    To place N number of queens on a NxN board, with none of them attacking each other.

The solution was not devised by Nadol Lueprapai, the creator simply implemented into it a Python project with humanized comments/outputs to better promote his own understanding. 
There is no intent to misrepresent this project as Nadol Lueprapai's original ideas.
https://www.geeksforgeeks.org/dsa/n-queen-problem-backtracking-3/ was an excellent learning resource for building this project.
